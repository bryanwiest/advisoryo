Remote code execution in NetGate firmware web interface

  • by Example Networks GmbH
  • Tracking ID EXN-SA-2026-007
  • Version 2, updated 17 Oct 2026
Download CSAF JSON Open in Secvisogram

Summary

The diagnostics page of the NetGate web interface passes user input to a shell command without sanitising it. An unauthenticated attacker on the management network can execute arbitrary commands with root privileges. Firmware 4.2.1 fixes the issue.

Vulnerabilities

CVE-2026-41021

Weakness
CWE-78, OS command injection
CVSS 3.1
9.8 Critical
Vector
CVSS:3.1/AV:N/AC:L/PR:N/UI:N/S:U/C:H/I:H/A:H

The host parameter of the ping tool on the diagnostics page is inserted into a shell command unchanged.

Remediation

  • Vendor fix

    Update the firmware to version 4.2.1 or later.

  • Workaround

    Restrict access to the web interface to trusted management hosts.
