Validation result (example)

If a document is invalid, nothing is published and every error is listed with its location in the document.

  • /document/tracking/version The version must match the last entry of the revision history.
  • /product_tree/branches/0/branches/1/product/product_id The product ID CSAFPID-0002 is defined twice.
  • /vulnerabilities/0/cve CVE-26-41021 is not a valid CVE ID (expected format CVE-YYYY-NNNN).
